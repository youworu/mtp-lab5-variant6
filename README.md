## Установка и запуск

Нужен Python 3.10 или новее с Tkinter. Проверить Tkinter можно командой
`python -m tkinter`: должно открыться небольшое тестовое окно.

Windows PowerShell:

```powershell
git clone https://github.com/youworu/mtp-lab5-variant6.git
cd mtp-lab5-variant6
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

В Linux используется `.venv/bin/python`; Tkinter может потребовать установки
пакета `python3-tk` средствами дистрибутива. Для запуска нужен графический сеанс.

## Вкладка «Основное»

1. Ввести текст и нажать «Показать текст» или Enter. Результат появится под полем.
   Для пустого поля выводится просьба ввести текст.
2. Нажать «Запустить» у прогрессбара. Значение увеличивается от 0 до 100%.
   «Пауза» сохраняет текущую позицию, «Запустить» продолжает, «Сбросить»
   возвращает значение к нулю. После завершения запуск начинается заново.
3. Нажать «Выбрать файл…». Откроется системный диалог; после выбора показывается
   полный путь. Для примера можно выбрать [examples/sample.txt](examples/sample.txt).
   При отмене диалога предыдущий выбор сохраняется.

Прогресс обновляется через `after`, поэтому во время его работы можно
набирать текст и переключать вкладки.

## Вкладка «График»

В окно Tkinter встроен `FigureCanvasTkAgg` с графиком `y = ax² + bx + c`.
По умолчанию показана функция `y = x²` на отрезке от −5 до 5.

Изменить коэффициенты и нажать «Построить». Например, `a=1`, `b=0`, `c=-2`
сдвигает параболу вниз. При `a=0` можно построить прямую или постоянную функцию.
В дробных коэффициентах допустимы точка и запятая.

Ошибки ввода, `NaN`, бесконечность и слишком большие значения показываются
над графиком; предыдущий корректный график сохраняется. Количество точек
задаётся целым числом, поэтому расчёт не зависит от накопления ошибки шага.

## Вкладка «Чат»

Чат работает между экземплярами программы на одном компьютере через TCP,
адрес — `127.0.0.1`, порт по умолчанию — `8765`.

Первый экземпляр:

```powershell
.\.venv\Scripts\python.exe main.py --name "Дарья"
```

На вкладке «Чат» нажать «Создать чат». Это запускает сервер и подключает
первого участника.

В другом терминале из той же папки запустить второй экземпляр:

```powershell
.\.venv\Scripts\python.exe main.py --name "Собеседник"
```

Открыть «Чат» и нажать «Подключиться». После этого можно обмениваться
сообщениями через «Отправить» или Enter. Сообщение появляется у обоих участников
после получения серверной рассылки.

Если порт занят, оба экземпляра можно запустить с другим одинаковым портом:

```powershell
.\.venv\Scripts\python.exe main.py --name "Дарья" --port 8766
.\.venv\Scripts\python.exe main.py --name "Собеседник" --port 8766
```

«Отключиться» завершает соединение одного участника. Сервер продолжает работать
до кнопки «Остановить свой сервер» или закрытия окна, где он был создан.
Остальные участники видят, что соединение закрыто, и могут подключиться снова
после нового запуска сервера.

Имя содержит от 1 до 30 символов, сообщение — от 1 до 1000. Пустые значения
отклоняются. Если сервер не запущен, показывается сообщение об ошибке
подключения.

Сетевое чтение выполняется в отдельных потоках. Они складывают сообщения
в очередь, а главный поток Tkinter обновляет историю через `after`.
Сообщения передаются как UTF-8 JSON с разделением по строкам. Сообщения
не сохраняются между запусками программы.

## Проверки

Установить инструменты разработки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Проверки без открытия окон:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

В этом режиме проходят 19 тестов математики и TCP-обмена, а 18 GUI-тестов
пропускаются. Для сетевых тестов выбираются свободные локальные порты.

Полная проверка с настоящими виджетами Tkinter:

```powershell
$env:RUN_GUI_TESTS = "1"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m flake8 .
```

Полный набор — 37 тестов: 7 для расчёта графика, 12 для чата и 18 для GUI.
Проверяются кнопки, обновление прогресса через цикл событий, отмена выбора
файла, встраивание matplotlib, ошибки коэффициентов, обмен между вкладкой чата
и вторым клиентом, завершение обработчиков при закрытии окна.
В GUI-тестах системный диалог подменяется, чтобы тесты не ждали ручного выбора.

Для ручной проверки открыть настоящий диалог выбора файла, перестроить график
и обменяться сообщениями между двумя отдельными окнами по шагам выше.

## Структура

- `main.py` — запуск и параметры имени/порта.
- `app.py` — главное окно с тремя вкладками.
- `widgets_tab.py` — текст, прогрессбар и диалог выбора файла.
- `plotting.py` — расчёт точек без GUI.
- `plot_tab.py` — встроенный график matplotlib.
- `chat.py` — TCP-сервер и клиент.
- `chat_tab.py` — интерфейс чата.
- `tests/` — проверки логики, сети и интерфейса.
