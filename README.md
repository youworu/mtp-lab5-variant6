## План работы

Одно приложение Tkinter с тремя вкладками. Расчёт точек графика и сетевой
обмен вынесены из интерфейса. Прогресс обновляется через `after`, сообщения
из сетевых потоков передаются интерфейсу через очередь.

Проверки включают математику графика, обмен между двумя TCP-клиентами,
обработчики виджетов и реальный запуск окон. Из внешних библиотек нужен
matplotlib, для проверки стиля — flake8.
